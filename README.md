Project Repo: https://github.com/SamuelProvenzano180/NEAT



This repository was developed primarily as a personal project and a portfolio piece to demonstrate C++ GDExtension development and machine learning integration (NEAT) within Godot 4.5+.

While the pre-compiled binaries, core functions, and example code are provided for anyone dedicated to using it, please note that this is not an actively maintained community plugin. Documentation covers the essentials, but advanced implementation will likely require familiarity with NEAT architecture and reading the source code. Feel free to fork and experiment!
